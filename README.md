# Website Sanjiro

Proyek website sederhana yang saya buat pada semester 3 sebagai latihan pengembangan web menggunakan HTML dan CSS. Melalui proyek ini, saya belajar menyusun halaman, mengatur tampilan, menampilkan gambar dan video, serta menghubungkan navigasi antarhalaman.

Website ini memiliki halaman utama dan halaman kontak. Proyek ini masih berupa website statis untuk pembelajaran; beberapa tombol dan form hanya berupa contoh tampilan.

## Teknologi

- HTML untuk struktur dan isi halaman.
- CSS untuk warna, ukuran, jarak, dan tata letak.
- Font Awesome untuk ikon melalui koneksi internet.

## Isi Proyek

| File / Folder | Keterangan |
| --- | --- |
| `main-web.html` | Halaman utama website. |
| `contact.html` | Halaman kontak dan identitas pembuat. |
| `style.css` | Pengaturan tampilan kedua halaman. |
| `Image/` | Folder gambar dan video yang digunakan website. |

## Cara Membuka Website

1. Pada halaman repository GitHub, klik **Code**, lalu pilih **Download ZIP**.
2. Ekstrak ZIP ke folder di komputer.
3. Buka folder hasil ekstrak yang berisi `main-web.html`.
4. Klik dua kali `main-web.html` untuk membukanya di browser, seperti Google Chrome, Microsoft Edge, atau Firefox.
5. Gunakan menu **Contact** untuk membuka halaman kontak dan **Home** untuk kembali ke halaman utama.

Pastikan `main-web.html`, `contact.html`, `style.css`, dan folder `Image` berada dalam satu folder yang sama. Nama file gambar dan video harus sesuai dengan yang tertulis di kode, termasuk huruf besar-kecilnya.

Website dapat dibuka langsung tanpa instalasi tambahan atau server. Koneksi internet diperlukan untuk memuat ikon Font Awesome.

## Hal yang Dipelajari

- Menyusun struktur halaman dengan HTML.
- Menggunakan class dan selector CSS.
- Mengatur tata letak, warna, serta jarak antarbagian.
- Menampilkan gambar dan video.
- Membuat tautan antarhalaman dan navigasi ke bagian tertentu.
